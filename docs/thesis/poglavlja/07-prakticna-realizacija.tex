\label{sec:opis-sistema}

\label{sec:tok-prevodjenja}
\napomena{Jedan program kroz sve faze: tokeni → stavke programa → tabela simbola
nakon prvog prolaza → mašinski kod nakon drugog prolaza.}

\section{Analiza rada asemblera}
\label{sec:analiza-rada}
